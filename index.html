Serverless Online HTML Viewer on AWS

A web app that runs with no servers at all. Users can upload an HTML file, preview it live in the browser, download it, copy the code and share a link. A light and dark theme button makes it comfortable to use.

The files are stored in Amazon S3 and delivered over HTTPS by Amazon CloudFront, so it loads fast for users around the world. All the app logic is plain HTML, CSS and JavaScript in the browser.
